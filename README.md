# CU killer bot

Telegram бот для игры в Killer для Центрального Университета

## Запуск

-   Скачайте проект

```bash
git clone <>
```

-   Скопируйте и измените настройки env

```bash
./env/setup_env.sh
```

-   Поднимите контейнеры

```bash
docker compose up -d --build
```

-   Чтобы остановить

```bash
docker compose down
```
